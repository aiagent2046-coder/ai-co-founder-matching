Статус: черновик для реализации (Tue 2026-06-30). Путь **Р3** — расширяем основной
`psycho`-движок в `app/api/discover/match/route.ts`. `lib/soul-matrix.ts` НЕ трогаем.

## 1. Новые факторы

### 1.1 HEXACO (гибрид: 6 доменов + ключевые фасеты)

Решение: НЕ полный 24-фасетный HEXACO-PI (слишком тяжёлый онбординг → drop-off),
а 6 доменов + 2-3 фасета, наиболее предиктивных для ко-фаундерства.

**6 доменов** (шкала 0-100 каждый):
- `H` — Honesty-Humility (уже частично есть как `behavioral_profile.honesty_humility`)
- `E` — Emotionality
- `X` — eXtraversion
- `A` — Agreeableness
- `C` — Conscientiousness
- `O` — Openness

**Ключевые фасеты** (выбраны как самые значимые для партнёрства основателей):
- `H.fairness` — честность в дележе (анти-эксплуатация партнёра)
- `C.diligence` — доведение до результата (рабочая надёжность)
- `A.flexibility` — готовность идти на компромисс (анти-клинч)

**Структура поля** `hexaco jsonb`:
```json
{
  "domains": { "H": 70, "E": 45, "X": 60, "A": 55, "C": 80, "O": 75 },
  "facets":  { "fairness": 72, "diligence": 85, "flexibility": 50 }
}
```

**Совместимость `hexacoCompat(a, b) -> 0..1`:**
HEXACO для команды — это микс «похожесть по ценностным» + «комплементарность по
рабочим». Эмпирическое правило (литература по team composition):
- `H` (честность): **похожесть важна** — большой разрыв = риск конфликта ценностей.
  `1 - |Ha-Hb|/100`, вес 0.30.
- `C` (добросовестность): **умеренная похожесть** (оба должны доводить дела).
  `1 - |Ca-Cb|/100`, вес 0.20.
- `A` (уживчивость): **похожесть**, но штраф если ОБА очень низкие (двойной клинч).
  `1 - |Aa-Ab|/100`, минус penalty если `Aa<30 && Ab<30`. вес 0.15.
- `X` (экстраверсия): **лёгкая комплементарность** (один драйвит, другой держит фокус).
  bell-curve вокруг разницы ~30%. вес 0.15.
- `O` (открытость): **похожесть** (общий взгляд на инновации). вес 0.10.
- `E` (эмоциональность): нейтрально, лёгкая похожесть. вес 0.10.
- Фасеты — модификатор ±: высокая `fairness` обоих +0.05; низкая `diligence`
  любого −0.05; высокая `flexibility` хотя бы одного гасит A-penalty.

Итог нормируется в 0..1.

### 1.2 Time-zone fit

**Источник:** автодетект `Intl.DateTimeFormat().resolvedOptions().timeZone` в браузере
+ подтверждение пользователем. Хранение: `time_zone text` (IANA, напр. `Europe/Moscow`).

**Совместимость `tzFit(a, b) -> 0..1`:** не равенство зон, а **overlap рабочих часов**.
- Перевести зоны в UTC-офсет (учесть, что офсет сезонный — берём текущий).
- `diff = |offsetA - offsetB|` в часах (по кратчайшей дуге, max 12).
- Предполагаемое рабочее окно 9 часов (10:00-19:00 локально). Overlap:
  `overlap = max(0, 9 - diff)` часов.
- `tzFit = overlap / 9`. То есть diff=0 → 1.0; diff=3 → 0.67; diff>=9 → 0.0.
- Если у одного из профилей `time_zone` нет → нейтрально 0.5 (не штрафуем за отсутствие).

### 1.3 Work-style complementarity

**Структура поля** `work_style jsonb` (4 оси, каждая 0-100):
```json
{
  "pace":          60,   // 0=методичный/медленный … 100=спринтер/быстрый
  "structure":     40,   // 0=хаос/гибкость … 100=процессы/планирование
  "communication": 70,   // 0=асинхрон/письменно … 100=синхрон/созвоны
  "risk":          55    // 0=осторожный … 100=рисковый
}
```

**Совместимость `workStyleCompat(a, b) -> 0..1`:** смесь похожести и комплементарности:
- `pace`: **похожесть** (разный темп = трение в ежедневной работе). `1-|d|/100`, вес 0.30.
- `structure`: **комплементарность** (один структурирует, другой драйвит хаос —
  но не крайности). bell-curve вокруг разницы ~35%. вес 0.25.
- `communication`: **похожесть** (рассинхрон async/sync — больно). `1-|d|/100`, вес 0.25.
- `risk`: **умеренная похожесть** (большой разрыв риск-аппетита = конфликт решений,
  но небольшой разрыв полезен). bell-curve вокруг ~20%. вес 0.20.

## 2. Итоговая формула (за флагом PSYCHO_V2_ENABLED)

Текущая (v1): `similarity*0.6 + ocean*0.4`, затем `* intentCompat`.

Новая (v2), все компоненты 0..1:
```
base_v2 = similarity     * 0.35
        + oceanComplement* 0.20
        + hexacoCompat    * 0.15
        + workStyleCompat * 0.15
        + tzFit           * 0.15
hybrid  = base_v2 * intentCompat
```
- Сумма весов = 1.00. Веса вынесены в именованные константы — легко тюнить.
- `behavioralBreakdown` (Thomas-Kilmann + red-flags) сохраняется как сейчас —
  red-flags остаются хард-сигналом (penalty/flags в выдаче).
- Хард-фильтр `intentCompat < 0.2` сохраняется.
- Деградация: любой отсутствующий фактор → нейтральные 0.5, не ломает выдачу.
